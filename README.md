# CodeDock Studio 3.0

Мобильный редактор HTML/CSS/JS как PWA: дерево файлов, вкладки, поиск с заменой,
предпросмотр с консолью, выгрузка проекта в ZIP и офлайн-режим.

## Файлы

```
codedock-studio/
├── index.html                 # всё приложение (разметка, стили, логика)
├── manifest.json              # PWA: иконки 192/512/maskable, standalone
├── sw.js                      # service worker, версия кэша codedock-v7
├── icon-192.png               # иконки из вашего icon.png
├── icon-512.png
├── icon-maskable-512.png
├── apple-touch-icon-180.png
├── icon.png                   # 512, для старых ссылок
├── logo.png                   # обрезанный и сжатый логотип (26 КБ вместо 890)
├── assets-src/                # исходные logo.png и icon.png (для пересборки)
├── scripts/
│   ├── build-assets.py        # иконки и логотип из исходников
│   └── test-app.js            # тесты без браузера (DOM-заглушка)
└── index.pasted.html          # предыдущая версия 2.0, для сравнения
```

## Что исправлено (P0)

- **Иконки.** Было: один `icon.png` 849×696, заявленный как 192 и 512.
  Стало: 192, 512 и отдельная maskable (рисунок в безопасной зоне), apple-touch 180.
- **Логотип** сжат с 890 КБ до 26 КБ (206×112, прозрачный фон).
- **Хранилище.** Сохранение с задержкой 500 мс вместо записи на каждый символ;
  вторая копия в `codedock_v3_backup`; проверка формы дерева при загрузке;
  при повреждении основного ключа поднимается резервная копия с уведомлением;
  при переполнении квоты — сообщение с кнопкой «Скачать ZIP».
- **Удаление** спрашивает не подтверждение, а даёт отмену в тосте (7 секунд).
- **Переименование** проверяет дубликаты имён в папке.
- **Предпросмотр** вставляет только подключённые в HTML файлы и на их места:
  `<link rel=stylesheet>` → `<style>`, `<script src>` → inline (с сохранением
  `type="module"`), порядок скриптов больше не меняется. Внешние ссылки не трогаются.
- **Sandbox** iframe: `allow-scripts allow-modals` без `allow-same-origin`.
- **Консоль** ловит `error`, `unhandledrejection` и показывает стек; на ошибку
  появляется красная точка на кнопке консоли.
- **Кнопка «Назад»** закрывает верхнюю панель и не плодит записи истории.

## Что добавлено (P1)

- Поиск и замена по файлу (Ctrl+F), счётчик совпадений, «Заменить» / «Все».
- Автоотступ по Enter, автозакрытие скобок и кавычек, Shift+Tab, отступ блока.
- Собственный стек отмены/повтора (Ctrl+Z / Ctrl+Y), 100 шагов на файл.
- Экспорт: ZIP (настоящий, store-метод, проверен `zipfile`) и JSON; импорт JSON.
- Тосты вместо `alert`/`confirm`; подтверждения — в модалке.
- Настройки: размер шрифта, размер отступа, перенос строк — сохраняются.
- Индикатор сохранения («Сохранено в 14:32») и кнопка перезапуска предпросмотра.
- Service worker: precache оболочки и шрифтов Font Awesome, кэшируются только
  успешные ответы, обновление через тост «Доступна новая версия».
- Доступность: убраны `user-scalable=no`, добавлены `aria-label`, `role="dialog"`.

## Проверка

```bash
node scripts/test-app.js
```

Тест поднимает DOM-заглушку, исполняет реальный скрипт страницы и проверяет:
загрузку, вкладки и дерево, правку файла, поиск/замену, удаление с отменой,
сборку предпросмотра из демо-проекта, консоль, настройки, кнопку «Назад»,
CRC32, ZIP (сигнатуры, число записей, CRC данных), размеры иконок и манифест,
а также отсутствие `alert`, `confirm`, `allow-same-origin` и `execCommand` в undo.

Иконки пересобираются из исходников:

```bash
python scripts/build-assets.py
```

## Локальный запуск и установка

```bash
python -m http.server 8000 --directory .
# открыть http://localhost:8000 — на localhost PWA устанавливается
```

Установка на телефон: Chrome → «Установить приложение», Safari → «На экран Домой».
Для установки нужен HTTPS или localhost — GitHub Pages подходит.

## Публикация

Скопируйте файлы в репозиторий `ramilka00100/codedock-studio` и запушьте:

```bash
git add index.html manifest.json sw.js icon*.png apple-touch-icon-180.png logo.png
git commit -m "CodeDock 3.0: PWA, сохранность данных, поиск, экспорт"
git push
```

После обновления старый service worker отдаст закэшированную версию один раз;
в приложении появится тост «Доступна новая версия» → «Обновить».
Принудительно: кнопка-логотип → «Очистить кэш».

## Ограничения

- Предпросмотр не подгружает картинки и ES-модули из виртуальных файлов:
  в проекте только текст, поэтому `import './x.js'` и `<img src>` из проекта
  работать не будут — CSS и JS инлайнятся, остальное остаётся как есть.
- Импорт — только JSON (ZIP пока только на выгрузку).
- При включённом переносе строк номера строк не выравниваются по визуальным строкам.
- Подсветки синтаксиса нет: редактор — это `<textarea>` с номерами строк.
- Данные лежат в `localStorage` (лимит ~5 МБ на домен). Для больших проектов
  используйте ZIP-выгрузку.
